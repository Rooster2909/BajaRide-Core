## III. Core Business Model Assumptions

### A. Operating Model

```
Provider/Owner → BajaRide Platform → Hub/Operations → End User
```

**Key Principle**: BajaRide does not own vehicles, does not directly operate experiences, and does not employ guides. The platform coordinates supply and demand.

### B. Revenue Generation Mechanism

**Primary**: Marketplace take rate applied to each booking transaction (GMV-based).

**Calculation**:
```
BajaRide Revenue per Booking = Booking Price × Take Rate %
```

## IX. Glossary

| Term | Definition |
|------|-----------|
| **GMV** | Gross Merchandise Value = total transaction value across all bookings |
| **Take Rate** | Percentage of GMV retained by BajaRide |
| **Unit Economics** | Revenue and cost per individual booking |
| **CAC** | Customer Acquisition Cost (for end users or providers) |
| **LTV** | Lifetime Value = total revenue generated by one customer over their lifetime |
| **Churn** | Percentage of users/providers who cease activity in a period |
| **Runway** | Number of months operations can continue with current cash burn |
| **Break-Even** | Monthly volume at which total revenue = total costs |

## I. Resumen Ejecutivo

Este documento describe el Modelo Financiero Maestro de BajaRide, un marketplace especializado en experiencias off-road. El modelo refleja un modelo de negocio asset-light en el que BajaRide funciona como una plataforma tecnológica y de coordinación, sin poseer vehículos ni activos operativos.

## III. Supuestos Centrales del Modelo de Negocio

### A. Modelo Operativo

```
Proveedor → BajaRide → Usuario
```

**Principio Clave**: BajaRide no posee vehículos, no opera directamente las experiencias y no emplea guías. La plataforma coordina la oferta y la demanda.

**Nota sobre el Hub**: El Hub/Operación es un componente futuro u opcional que la arquitectura puede contemplar más adelante, pero no es requisito para que una operación exista en el MVP (ver `06-App/MVP-Product-Definition.md`).

### B. Mecanismo de Generación de Ingresos

**Primario**: Take rate del marketplace aplicado a cada transacción de reserva (basado en GMV).

**Cálculo**:
```
Ingreso de BajaRide por Reserva = Precio de la Reserva × Take Rate %
```

## IX. Glosario

| Término | Definición |
|------|-----------|
| **GMV** | Gross Merchandise Value = valor total de transacciones a través de todas las reservas |
| **Take Rate** | Porcentaje del GMV retenido por BajaRide |
| **Economía Unitaria** | Ingreso y costo por reserva individual |
| **CAC** | Costo de Adquisición de Clientes (usuarios finales o proveedores) |
| **LTV** | Lifetime Value = ingreso total generado por un cliente durante su vida útil |
| **Churn** | Porcentaje de usuarios/proveedores que dejan de tener actividad en un periodo |
| **Runway** | Número de meses que la operación puede continuar con el nivel de gasto actual |
| **Break-Even** | Volumen mensual en el que el ingreso total = costos totales |

# BajaRide-Core

**BajaRide Master Intelligence Repository**

Repositorio central del proyecto BajaRide.

## Definición oficial

BajaRide es una **plataforma tecnológica y marketplace especializado en experiencias off-road** que conecta usuarios con propietarios, operadores y proveedores, organizando oferta, demanda, experiencias, reservas, pagos, confianza, operación y datos.

## Modelo base

**Propietario / Proveedor → BajaRide → Hub → Usuario**

BajaRide opera como infraestructura tecnológica y de coordinación. No depende de poseer una flota propia para funcionar.

## Enfoque inicial

- Geografía inicial: Ensenada, Baja California.
- Mercado: experiencias UTV/off-road.
- Modelo: asset-light marketplace.
- Prioridades: oferta, demanda, hubs, MVP, operación, validación y preparación para financiamiento.

## Estructura

- `00-Constitution` — principios y reglas del proyecto.
- `01-Master-Plan` — estrategia y hoja de ruta maestra.
- `02-Finance` — modelo financiero y economía unitaria.
- `03-Legal` — estructura legal, contratos y cumplimiento.
- `04-Marketing` — adquisición, marca y demanda.
- `05-Operations` — propietarios, proveedores, hubs, usuarios y piloto.
- `06-App` — producto, MVP y arquitectura técnica.
- `07-AI-System` — estado y protocolos de coordinación IA.
- `08-Investors` — documentación para inversión y financiamiento.
- `99-Archive` — material histórico u obsoleto.

## Fuente de verdad

Este repositorio es la fuente central de documentación del proyecto. Los documentos deben mantenerse alineados con el estado estratégico vigente.

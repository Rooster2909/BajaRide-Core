# BajaRide - AI Project State

## Misión

Construir la plataforma tecnológica y marketplace especializado en experiencias off-road, conectando usuarios con propietarios, operadores y proveedores bajo un modelo asset-light.

## Definición Estratégica Vigente

BajaRide es una **plataforma tecnológica y marketplace** (no una empresa de renta de vehículos).

- Modelo: **asset-light** — BajaRide no depende de poseer una flota propia.
- Rol: coordinación tecnológica y operativa del ecosistema.
- Modelo: Propietario/Proveedor → BajaRide → Hub/Operación → Usuario.
